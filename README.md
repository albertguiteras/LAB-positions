## 📖 Descripción

Práctica exhaustiva para comprender el flujo del documento y las propiedades de posicionamiento CSS (`static`, `relative`, `absolute`, `fixed`, `sticky`).

---

## 🎯 Objetivos y Conceptos Clave

- [x] Contexto de apilamiento (`z-index`) y contenedor posicionado
- [x] Posicionamiento absoluto (`position: absolute`) relativo a contenedor
- [x] Elementos fijos en pantalla (`position: fixed`) como barras y botones flotantes
- [x] Encabezados adhesivos con `position: sticky`
